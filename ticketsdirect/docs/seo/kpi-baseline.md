# SEO KPI baseline & tracking

How we tell whether the content strategy is working. Record the **baseline** the day the new pages go live, then review at 30 / 60 / 90 days. These are milestones, not guarantees — SEO depends on existing authority, competition, indexing, content quality and seasonality.

## Set up first
- **Google Search Console** — property verified for `excursionsticketsdirect.com`; submit the sitemap (`/sitemap.xml`, already generated by the build) and request indexing for each new URL below.
- **GA4** — organic channel segment; mark the booking-funnel events (see below) as conversions.
- The read-only export script (`npm run google`, service account) can pull GSC data into `.cache/google/` for monthly snapshots — never commit it (public repo).

## Search Console — track
Total organic clicks · impressions · average position · CTR · top queries · top pages · countries · indexed target pages (new page coverage).

## GA4 — track
Organic sessions · engagement rate · landing pages · **booking-button clicks** · booking-funnel progression (cart → details → request) · completed bookings · organic booking revenue · conversion rate.

Booking funnel already emits clear steps in the on-site system (`/book/` cart → details → confirmation). Wire GA4 events to: `add_to_booking` (tour page), `begin_checkout` (cart → details), `booking_request` (confirmation shown).
